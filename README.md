# PharmaGPT

AI Scientist for Drug Discovery and Biomedical Research.

---

## Vision

PharmaGPT aims to build an AI system capable of understanding molecules, proteins, biomedical literature, and drug interactions.

The long-term goal is to create a foundation model for drug discovery that can assist researchers in identifying promising compounds, predicting interactions, analyzing toxicity, and accelerating biomedical research.

---

## Core Objectives

* Molecular Representation Learning
* Protein Representation Learning
* Binding Affinity Prediction
* Toxicity Prediction
* Drug Similarity Search
* Drug Repurposing
* Biomedical Literature Understanding
